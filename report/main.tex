\section*{Abstract}
This study examines how preprocessing affects 3D object classification when point clouds contain distant outliers. Basis Point Sets (BPS) convert each cloud into distances from a shared set of reference points. A multilayer perceptron classifies the resulting vector. The original BPS normalization subtracts the mean and divides by the maximum radius. A distant point can increase this radius and shrink the main object in the normalized coordinates.

Three pipelines isolate this effect: mean centring with maximum scaling, median centring with maximum scaling, and median centring with 95th-percentile scaling. Each pipeline uses the same BPS basis and classifier architecture, trained on clean ModelNet40 point clouds with three training seeds. Evaluation replaces a controlled fraction of points with distant outliers at three distances. For the radius-five, two-percent condition, pipelines A, B and C achieve \PrimaryA\%, \PrimaryB\% and \PrimaryC\% mean overall accuracy, respectively. Clean accuracies are \CleanA\%, \CleanB\% and \CleanC\%. Geometry measurements connect prediction changes to object shrinkage and feature drift. Heavy contamination also tests the failure of percentile scaling. These findings concern a controlled distant-outlier model; they do not establish robustness to arbitrary sensor corruptions.

\section{Introduction}
An object point cloud is a collection of sampled surface coordinates. Unlike an image, it has no regular pixel grid and its point order has no geometric meaning. A classification method must map this representation to an object category while handling variation in sampling and coordinates.

BPS offers a direct route to a conventional classifier. It records distances from fixed reference locations to the cloud, giving every object a feature vector of the same length~\cite{bps}. The classifier can then use familiar fully connected layers. This separation makes preprocessing a useful subject for investigation: a coordinate change affects the entire feature vector before learning is applied.

\textbf{Research question.} Can robust centring and scaling reduce classification degradation caused by distant outliers while maintaining clean-data performance?

The work implements a BPS classifier, compares three normalization rules, and measures both predictive and geometric effects. The centring-only control distinguishes changes in location estimation from changes in scale estimation. The extension follows a limitation already identified in the BPS supplementary material. Its contribution is the specified classification experiment and analysis, rather than a claim that robust normalization is a new general method.

\section{Source Method and Scope of the Study}
\subsection{Basis Point Sets: the method used}
Prokudin, Lassner and Romero introduce Basis Point Sets as a fixed-length representation of a point cloud~\cite{bps}. A common set of reference locations is placed in space. For each location, the distance to the closest cloud point is recorded. These distances form a vector that can be classified by a multilayer perceptron. The present implementation uses this distance representation, the author's random-basis sampling procedure and the two-hidden-layer classification architecture supplied with the paper.

The BPS supplementary material also discusses a preprocessing limitation: distant outliers can change size normalization and make the main shape too small. That discussion concerns human-mesh registration and suggests robust normalization or synthetic noise as possible remedies. It motivates the present classification experiment; robust normalization itself is not claimed as a new idea.

\subsection{3D ShapeNets: the dataset source}
Wu et al. introduced ModelNet as a dataset of 3D CAD models~\cite{shapenets}. This study uses ModelNet40, which contains 40 object categories, through the public 2048-point HDF5 conversion distributed with PointNet. Only the dataset is taken from this source. The volumetric representation and neural network proposed in 3D ShapeNets are not implemented here. The HDF5 conversion and download mirror are credited separately in the reproducibility section.

\subsection{Implemented extension}
The experiment asks whether changing the centre and scale estimates preserves useful BPS features when a cloud contains distant outliers. Pipeline A uses the mean and maximum radius. Pipeline B changes only the centre to a coordinate-wise median. Pipeline C also replaces the maximum radius with the 95th percentile. B therefore tests whether robust centring alone explains any benefit observed in C.

The work consists of implementing these three pipelines, training clean-data classifiers under matched settings, and evaluating controlled outlier replacements. Geometric measurements test whether accuracy changes coincide with object shrinkage and changes in the BPS vector. Repeated training seeds measure variability, while heavier contamination checks where the proposed scale rule fails.

This is an experimental extension of an existing representation. It retains every corrupted point and does not perform denoising. Its evidence is limited to the specified synthetic corruption on ModelNet40; it does not establish robustness to all sensor errors or superiority over other classification architectures.

\section{Basis Point Set Classification}
Let a cloud be $X=\{x_i\}_{i=1}^{N}$, where $x_i\in\R^3$. A normalization rule produces $\widetilde X$. A shared basis $B=\{b_j\}_{j=1}^{K}$ is sampled once and retained for every training, validation and test object. The BPS distance feature is
\begin{equation}
 f_j(\widetilde X)=\min_{1\leq i\leq N}\|b_j-\widetilde x_i\|_2,
 \qquad f(\widetilde X)\in\R^K.
\end{equation}
The experiment uses $N=2048$ and $K=512$. Reference points are sampled uniformly within a ball of radius $1.7$, using basis seed 13. Nearest-point queries use a spatial search tree. The distances are not signed distances and do not require a watertight mesh.

\textbf{Permutation invariance.} Reordering the cloud changes neither the candidate set in the minimum nor the resulting feature. Each reference location retains its identity, so the feature vector has a fixed order even though the cloud does not. This property does not imply rotation invariance: rotating a cloud relative to the fixed basis can change its distances.

\fig{pipeline}{1.0}{The implemented classification pipeline. Only normalization differs between A, B and C. The BPS basis and classifier dimensions are shared.}

\subsection{Multilayer perceptron}
A perceptron computes a weighted sum and a decision. The classifier here extends this idea with two hidden layers and nonlinear activations. For a hidden layer,
\begin{equation}
 h=\operatorname{ReLU}(Wf+b),\qquad \operatorname{ReLU}(u)=\max(0,u).
\end{equation}
The implemented architecture is input batch normalization, a 512-unit linear layer, ReLU, batch normalization and dropout, followed by a second 512-unit block and a 40-logit output layer. Dropout probability is $0.8$, following the author example. The model has \ParameterCount\ trainable parameters.

For logits $z$ and category $y$, training minimizes multiclass cross-entropy,
\begin{equation}
 \mathcal L(z,y)=-z_y+\log\!\left(\sum_{c=1}^{40}\exp(z_c)\right).
\end{equation}
Backpropagation computes parameter gradients and Adam updates the parameters. At inference, the predicted class is the largest logit. Batch normalization uses stored training statistics and dropout is disabled. No labels or clean-coordinate statistics are supplied to the test-time normalization.

\section{Normalization and Outlier Model}
\subsection{Three normalization rules}
The baseline centre and scale are
\begin{equation}
 c_A=\frac1N\sum_i x_i,\qquad
 s_A=\max_i\|x_i-c_A\|_2,\qquad
 \widetilde x_i=\frac{x_i-c_A}{s_A}.
\end{equation}
Pipeline B substitutes the coordinate-wise median $c_M$ for the mean while retaining maximum scaling. Pipeline C also replaces the maximum by the 95th percentile:
\begin{equation}
 s_B=\max_i\|x_i-c_M\|_2,\qquad
 s_C=Q_{0.95}\bigl(\{\|x_i-c_M\|_2\}_{i=1}^{N}\bigr).
\end{equation}
All scales are lower bounded by $10^{-8}$ to handle degenerate inputs. For C, the bulk of the cloud lies within a comparable radius; the entire cloud need not lie in the unit ball. No point is deleted, clipped or projected onto a sphere during normalization.

\subsection{Controlled distant outliers}
For each cloud, $m=\operatorname{round}(pN)$ points are selected without replacement. Their coordinates are replaced by
\begin{equation}
 x_i'=c_0+\rho r_0 u_i,\qquad \|u_i\|_2=1,
\end{equation}
where $c_0$ and $r_0$ are the uncorrupted cloud's mean and maximum radius. They define the synthetic corruption only; the classifier never receives them. Directions $u_i$ are independently sampled uniformly on the sphere. The point count remains 2048. Replacement also removes a small number of genuine samples, which is part of this protocol.

Nominal replacement fractions are 1, 2, 5 and 10 percent; distances are $\rho\in\{3,5,10\}$. Integer rounding gives 20, 41, 102 and 205 replaced points, respectively. The actual fractions are retained in the raw results. Object-specific seeds keep the selected points and directions matched across pipelines and distance conditions.

\section{Experimental Protocol}
\subsection{Data and model selection}
The processed dataset contains 9840 training clouds and 2468 test clouds across 40 categories. A fixed stratified split reserves 1968 training clouds for validation and uses the remaining 7872 for fitting. The official test membership remains unchanged. File URLs and SHA-256 hashes, class names, split indices and the BPS basis are saved with the experiment.

All classifiers are trained on clean clouds. There is no corruption augmentation, so the comparison isolates the normalization rule. Architecture, reference locations, split and optimizer settings are shared. Three training seeds, 13, 37 and 73, control initialization, dropout and batch shuffling. Corresponding pipelines use matched seeds.

\subsection{Evaluation and uncertainty}
Overall accuracy is the fraction of correctly classified test objects. Mean class accuracy averages the recall of the 40 categories, giving each category equal weight. Each nonzero severity has three corruption draws, with seeds 101, 202 and 303. The draws are averaged within each trained model; the reported mean and sample standard deviation then summarize the three training seeds. Repeated predictions of one object are not counted as independent new objects.

The final evaluation contains 333 model-condition rows. The configuration and model checkpoints are frozen before test prediction. Clean accuracy, robustness and failure cases are reported together. Evaluation logs distinguish classifier prediction from feature extraction with geometry diagnostics. The latter includes analysis overhead and is not a standalone preprocessing benchmark.

\section{Mechanism and Failure Analysis}
\fig{mechanism}{1.0}{Geometry diagnostics for outliers at five times the clean radius. Left: main-object shrinkage relative to clean preprocessing, measured on retained inliers. Right: relative Euclidean change in BPS features. The geometry measurements do not use classifier predictions.}

\subsection{Why maximum scaling can shrink the object}
If a clean object's radius is approximately one and a distant point appears at radius $\rho$, the maximum-based scale is approximately $\rho$. The main object's normalized dimensions are then approximately $1/\rho$ of their previous values. Median centring can stabilize location without preventing this scaling effect. This explains why B is a necessary control.

For C, a small number of extreme radii can fall above the selected percentile. The estimated scale can remain close to that of the main object. However, this is conditional on the distribution and fraction of contamination. Coordinate-wise medians do not guarantee the recovery of a true object centre, and percentile scaling does not remove bad points.

\subsection{Why the percentile rule can also fail}
When enough extreme points occupy the upper tail, the 95th percentile can itself fall among outlier radii. The ten-percent condition deliberately tests this situation. Finite sampling, quantile interpolation and the original radial distribution affect the transition; a universal exact threshold is not claimed.

Two effects must be distinguished. First, an outlier can change centring and scaling, shifting the locations of all genuine points relative to the basis. Second, an outlier can directly become the nearest neighbour of a basis point and alter that distance feature. The normalization variants target the first effect. The present distant-shell construction primarily stresses scale estimation; it does not adequately test arbitrary nearby clutter that can affect the second mechanism.

The illustration supports a geometric interpretation rather than a visual claim of denoising. Red points are retained in every pipeline. Classification conclusions come from the full test set rather than this selected visualization.

\section{Limitations and Further Work}
\textbf{Controlled corruption.} Spherical-shell replacement is designed to expose one failure mechanism. Real sensors produce structured missing regions, nonuniform density, pose variation and correlated errors. Accuracy in this experiment does not establish deployment readiness.

\textbf{Dataset scope.} ModelNet40 contains CAD-derived shapes. The study uses the standard processed split but does not include real scans or cross-dataset testing. It also studies object classification rather than detection or segmentation.

\textbf{Representation.} Basic BPS distances are point-order invariant but not generally rotation invariant. Reference count and radius are fixed. The percentiles are not asserted to be optimal for all categories or corruption types.

\textbf{Comparison scope.} The comparison is between three preprocessing rules within the same BPS--MLP architecture. Other classifiers and learned denoisers are not evaluated. A 95th percentile is a conventional robust statistic, and the source authors already suggest robust normalization. The work contributes an implementation and controlled classification analysis of that idea.

\textbf{Uncertainty.} Three training seeds and three corruption draws provide a limited view of variation. Error bars summarize training-seed variability after averaging draws; they are not confidence bounds for all future datasets. The same test objects recur across conditions.

\textbf{Next experiments.} A useful extension is a statistical outlier-removal baseline, with filter parameters chosen using validation data and clean-data effects measured explicitly. Clean-trained and noise-augmented classifiers could then separate preprocessing benefits from learned robustness. Nearby clutter, Gaussian jitter and missing regions should be tested with clearly specified protocols before moving to real scanned data.

\section{Conclusion}
The comparison identifies scale estimation as a failure mechanism in a clean-trained BPS classifier. Median centring alone leaves maximum-based shrinkage largely unchanged. Percentile scaling preserves the main-object size at low contamination, but loses this protection under heavy contamination.
